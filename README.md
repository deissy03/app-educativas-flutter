\# Aprende Jugando



\## Descripcion



Aprende Jugando es mi primera aplicacion movil desarrollada con Flutter y Dart.



Es un juego educativo dirigido a ninos para practicar operaciones matematicas basicas de una manera sencilla, interactiva y divertida.



La aplicacion permite practicar:



\- Sumas

\- Restas

\- Multiplicaciones



\## Objetivo



El objetivo de Aprende Jugando es apoyar el aprendizaje de las operaciones matematicas mediante un juego con preguntas, niveles, estrellas y una mascota que acompana al jugador.



\## Sistema de niveles



La aplicacion cuenta con 3 niveles.



Cada nivel contiene 10 preguntas.



Para superar un nivel se necesitan minimo 8 respuestas correctas de 10.



El juego incluye:



\- Preguntas matematicas

\- Respuestas correctas e incorrectas

\- Sistema de estrellas

\- Tres niveles

\- Mensajes de resultado

\- Mascota con diferentes estados



\## Desarrollo con apoyo de Inteligencia Artificial



Durante el desarrollo de esta aplicacion se utilizo Inteligencia Artificial como herramienta de apoyo para aprender, planificar, desarrollar y documentar el proyecto.



\### 1. Crear un buen prompt



El primer paso consiste en explicar correctamente a la Inteligencia Artificial que aplicacion se quiere desarrollar.



El prompt debe indicar:



\- Nombre de la aplicacion.

\- Objetivo.

\- Usuarios.

\- Funcionalidades.

\- Pantallas.

\- Diseno visual.

\- Colores.

\- Navegacion.

\- Reglas del juego.

\- Tecnologias que se desean utilizar.



Mientras mas clara sea la informacion proporcionada, mas precisa puede ser la orientacion de la IA.



\### 2. Crear el expediente tecnico



Antes o durante el desarrollo se puede solicitar a la Inteligencia Artificial la elaboracion de un expediente tecnico.



El documento puede incluir:



\- Descripcion de la aplicacion.

\- Objetivos.

\- Alcance.

\- Requerimientos funcionales.

\- Requerimientos no funcionales.

\- Diseno de la aplicacion.

\- Estructura de las pantallas.

\- Navegacion.

\- Tecnologias utilizadas.

\- Logica de funcionamiento.

\- Recursos utilizados.

\- Pruebas.

\- Instalacion.

\- Generacion del APK.



El expediente tecnico puede solicitarse en formato PDF para conservar la documentacion completa del proyecto.



\### 3. Preparar el entorno de desarrollo



Para desarrollar la aplicacion movil se instala y configura el entorno necesario para trabajar con Flutter.



En este proyecto se utilizaron:



\- Flutter.

\- Dart.

\- PowerShell.

\- Android Studio.

\- Visual Studio Code.



PowerShell se utilizo para ejecutar los comandos necesarios durante la creacion, configuracion, ejecucion y compilacion del proyecto.



\### 4. Crear el proyecto



Una vez preparado el entorno, se crea el proyecto utilizando Flutter.



La Inteligencia Artificial puede ayudar a indicar los comandos necesarios y explicar donde se debe crear el proyecto.



Tambien se puede indicar a la IA la ubicacion exacta donde fue creado el proyecto para continuar trabajando sobre esa carpeta.



\### 5. Ejecutar y probar la aplicacion



Durante el desarrollo, la aplicacion puede ejecutarse y probarse en diferentes dispositivos.



En este proyecto se utilizo Chrome para visualizar y probar la aplicacion durante el desarrollo.



Tambien se realizaron pruebas en Windows y posteriormente se genero una version para Android.



\### 6. Desarrollar las funcionalidades



La Inteligencia Artificial puede utilizarse como apoyo durante la programacion para:



\- Crear codigo.

\- Explicar codigo.

\- Detectar errores.

\- Corregir errores.

\- Mejorar interfaces.

\- Implementar funcionalidades.

\- Explicar comandos.

\- Organizar el proyecto.

\- Orientar sobre la estructura de Flutter.



La IA funciona como una herramienta de apoyo al aprendizaje y al desarrollo, mientras que el proyecto es probado y revisado durante todo el proceso.



\### 7. Generar el APK



Una vez terminada y probada la aplicacion, se puede solicitar ayuda a la Inteligencia Artificial para generar el APK de Android.



El APK permite instalar la aplicacion directamente en un dispositivo Android sin necesidad de instalar Flutter en el telefono.



\### 8. Crear documentacion para GitHub



Finalmente, tambien se puede solicitar a la Inteligencia Artificial que ayude a crear un archivo README.md en Markdown para presentar el proyecto en GitHub.



Este archivo puede incluir:



\- Descripcion del proyecto.

\- Objetivo.

\- Caracteristicas.

\- Tecnologias utilizadas.

\- Instalacion.

\- Ejecucion.

\- Generacion del APK.

\- Capturas de pantalla.

\- Informacion de la autora.



De esta manera, la Inteligencia Artificial puede apoyar diferentes etapas del proyecto: desde la planificacion y programacion hasta la documentacion y presentacion final.
